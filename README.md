# better-nm (`bnm`)

A NetworkManager front end that doesn't suck. One Go daemon, three surfaces (CLI, TUI, desktop), unified control of Tailscale, WireGuard and OpenVPN, continuous network-quality monitoring with per-network baselines, and an on-demand speed test.

Status: being charted. The plan lives as a wayfinder map in this repo's issues (label `wayfinder:map`).
